읽어보세요

블록 하나는 파이썬 한 줄과 같은 일을 합니다. 대응표에서 왼쪽 블록을 보고 오른쪽 코드를 읽어 보세요.

C ▾반사광 = color_sensor.reflection(port.C)

C 포트에 연결된 컬러 센서가 받은 빛의 양을 0~100 사이 숫자로 알려줍니다. 둥근 블록(값 블록)은 파이썬에서 값을 돌려주는 함수가 됩니다.

먼저 읽기

단위가 다른 곳 7가지

블록과 파이썬은 같은 일을 하지만 숫자의 단위가 다른 곳이 있어요. 블록 숫자를 그대로 옮기면 로봇이 다르게 움직입니다.

시간
1 초 → 1000 ms
파이썬은 밀리초(1/1000초)를 씁니다.
모터 속도
50 % → 약 500 °/s
파이썬은 초당 회전 각도(도/초). 대략 1%≈10°/s로 생각하세요.
모터 출력(확장)
100 % → 10000
출력(듀티 사이클)은 -10000~10000. %에 100을 곱합니다.
회전 수
1 회전 → 360 °
파이썬은 회전 수 대신 각도로 지정합니다.
거리 센서
10 cm → 100 mm
파이썬은 mm로 알려주고, 아무것도 없으면 -1이 나옵니다.
라이트 매트릭스 좌표
1~5 → 0~4
파이썬은 0부터 셉니다. 블록 (1,1)은 파이썬 (0,0)입니다.
기울기 각도
90 ° → 900
파이썬은 0.1도 단위라서 10으로 나눠야 블록 값과 같아집니다.
모든 프로그램의 첫 줄

불러오기(import)

블록은 팔레트에 이미 다 있지만, 파이썬은 쓸 도구를 맨 위에서 불러와야 합니다. 아래 줄을 복사해서 시작하면 이 표의 모든 코드를 쓸 수 있어요.

from hub import port, light_matrix, light, sound, button, motion_sensor
import motor, motor_pair, color_sensor, distance_sensor, force_sensor
import color, runloop, random, time
