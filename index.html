스파이크 블록 ↔ 파이썬 대응표

블록 하나는 파이썬 한 줄과 같은 일을 합니다. 왼쪽 블록을 보고 오른쪽 코드를 읽어 보세요. 기준은 SPIKE 앱 3 버전의 파이썬입니다.

C ▾반사광 = color_sensor.reflection(port.C)

C 포트에 연결된 컬러 센서가 받은 빛의 양을 0~100 사이 숫자로 알려줍니다. 둥근 블록(값 블록)은 파이썬에서 값을 돌려주는 함수가 됩니다.

먼저 읽기

단위가 다른 곳 6가지

블록과 파이썬은 같은 일을 하지만 숫자의 단위가 다른 곳이 있어요. 블록 숫자를 그대로 옮기면 로봇이 다르게 움직입니다.

시간
1 초 → 1000 ms
파이썬은 밀리초(1/1000초)를 씁니다.
모터 속도
50 % → 약 500 °/s
파이썬은 초당 회전 각도(도/초). 대략 1%≈10°/s로 생각하세요.
회전 수
1 회전 → 360 °
파이썬은 회전 수 대신 각도로 지정합니다.
거리 센서
10 cm → 100 mm
파이썬은 mm로 알려주고, 아무것도 없으면 -1이 나옵니다.
빛 매트릭스 좌표
1~5 → 0~4
파이썬은 0부터 셉니다. 블록 (1,1)은 파이썬 (0,0)입니다.
기울기 각도
90 ° → 900
파이썬은 0.1도 단위라서 10으로 나눠야 블록 값과 같아집니다.
모든 프로그램의 첫 줄

불러오기(import)

블록은 팔레트에 이미 다 있지만, 파이썬은 쓸 도구를 맨 위에서 불러와야 합니다. 아래 줄을 복사해서 시작하면 이 표의 모든 코드를 쓸 수 있어요.

from hub import port, light_matrix, light, sound, button, motion_sensor
import motor, motor_pair, color_sensor, distance_sensor, force_sensor
import color, runloop, random

예제: 검은 선 따라가기

위의 블록들을 모으면 프로그램이 됩니다. 블록의 들여쓰기(C자 안에 들어간 블록)는 파이썬의 들여쓰기 4칸과 똑같은 뜻이에요.

프로그램이 시작되면 이동 모터를 A+B ▾로 설정 무한 반복하기
만약 C ▾반사광 < ▾50%? 라면
왼쪽 20% 오른쪽 50%로 이동 시작
아니면
왼쪽 50% 오른쪽 20%로 이동 시작 
from hub import port
import motor_pair, color_sensor, runloop

async def main():                                  # 프로그램이 시작되면
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.B)
    while True:                                    # 무한 반복하기
        if color_sensor.reflection(port.C) < 50:   # 만약 반사광 < 50% 라면
            motor_pair.move_tank(motor_pair.PAIR_1, 200, 500)
        else:                                      # 아니면
            motor_pair.move_tank(motor_pair.PAIR_1, 500, 200)
        await runloop.sleep_ms(10)

runloop.run(main())

· 반사광이 50보다 작으면(검은 선 위) 왼쪽으로, 크면(흰 바탕) 오른쪽으로 꺾으며 선 가장자리를 따라갑니다.

· 마지막 await runloop.sleep_ms(10)은 블록에는 없지만 반복이 너무 빨리 돌지 않게 잠깐 쉬는 줄입니다.
